`RFID_Test` is the Pico USB-serial UID demonstration. See `RFID_Test/README.md`
for wiring and build instructions. It requires `ABYSSAL_USE_PICO_SDK=ON` and
runs on the Pico, not through desktop CTest.

The other test folders remain host-buildable placeholders owned by the other
modules. Replace them with independent tests while preserving the target names.
